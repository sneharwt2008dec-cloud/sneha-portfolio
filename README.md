# Sneha Rawat — Personal Portfolio

A responsive personal portfolio website made with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/profile.png` — your uploaded profile photo

## Before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your email address.
3. Replace the `#` values on Instagram and GitHub links with your real profile URLs.
4. Edit any text you want to personalize.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `sneha-portfolio`.
2. Upload all files and the `assets` folder (keep the same folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your live website URL in the Pages section.

Your website address will usually look like:
`https://YOUR-USERNAME.github.io/sneha-portfolio/`
